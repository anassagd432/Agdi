Z.AI

Z.AI is the API platform for GLM models. It provides REST APIs for GLM and uses API keys for authentication. Create your API key in the Z.AI console. AGDI uses the zai provider with a Z.AI API key.

CLI setup

agdi onboard --auth-choice zai-api-key
# or non-interactive
agdi onboard --zai-api-key "$ZAI_API_KEY"

Config snippet

{
  env: { ZAI_API_KEY: "sk-..." },
  agents: { defaults: { model: { primary: "zai/glm-5" } } },
}

Notes

  • GLM models are available as zai/<model> (example: zai/glm-5).
  • See /providers/glm for the model family overview.
  • Z.AI uses Bearer auth with your API key.
