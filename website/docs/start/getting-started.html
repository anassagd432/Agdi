Getting Started

Goal: go from zero to a first working chat with minimal setup.

Fastest chat: open the Control UI (no channel setup needed). Run agdi dashboard and chat in the browser, or open http://127.0.0.1:18789/ on the gateway host. Docs: Dashboard and Control UI.

Prereqs

  • Node 22 or newer

Check your Node version with node --version if you are unsure.

Quick setup (CLI)

    ```bash
    curl -fsSL https://agdi.ai/install.sh | bash
    ```
    <img

src="/assets/install-script.svg" alt="Install Script Process" className="rounded-lg" />

    ```powershell
    iwr -useb https://agdi.ai/install.ps1 | iex
    ```
  



Other install methods and requirements: [Install](/install).




```bash
agdi onboard --install-daemon
```

The wizard configures auth, gateway settings, and optional channels.
See [Onboarding Wizard](/start/wizard) for details.



If you installed the service, it should already be running:

```bash
agdi gateway status
```



```bash
agdi dashboard
```
If the Control UI loads, your Gateway is ready for use.

Optional checks and extras

Useful for quick tests or troubleshooting.

```bash
agdi gateway --port 18789
```



Requires a configured channel.

```bash
agdi message send --target +15555550123 --message "Hello from AGDI"
```

Useful environment variables

If you run AGDI as a service account or want custom config/state locations:

  • AGDI_HOME sets the home directory used for internal path resolution.
  • AGDI_STATE_DIR overrides the state directory.
  • AGDI_CONFIG_PATH overrides the config file path.

Full environment variable reference: Environment vars.
