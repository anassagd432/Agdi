# `agdi setup`

Initialize `~/.agdi/agdi.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
agdi setup
agdi setup --workspace ~/.agdi/workspace
```

To run the wizard via setup:

```bash
agdi setup --wizard
```
