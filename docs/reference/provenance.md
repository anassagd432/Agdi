# Provenance

AGDI is independently maintained. The repository is a modified derivative of
OpenClaw. This page records what the git history, package metadata, and a
blob comparison can support. It does not state legal conclusions beyond the
license text.

The comparison snapshot of OpenClaw tag `v2026.3.24` was retrieved at
2026-09-21T21:58:22+02:00. Mutable public counts live in the
[Phase 1 baseline](/audits/phase1-baseline-2026-09-21). Notices for
recipients live in the repository-root file `THIRD_PARTY_NOTICES.md`.

## How the baseline was judged

Blob identity uses git object ids from `git ls-tree -r` in this repository and
the GitHub Git Trees API for OpenClaw commit
`cff6dc94e30794a269eb7805b6e636c3634a088c`. Equal ids mean equal file bytes.
The tag is the closest verified release because:

- the first commit message names `v2026.3.24`
- the first `package.json` version is `2026.3.24`
- the tag date (2026-03-25) is two days before the import commit (2026-03-27)
- 97.08% of shared paths match that tag
- later local commits named `up` (`8eefba4843e821bb53b6c6c8e903cd89b4e43e64`
  and `c8064565f95602f96685944d8a57fe0cdea9f033`) do not name an upstream SHA,
  and the second of those commits matches fewer paths in the same tag

Neighboring tags were resolved but not given full tree comparisons:
`v2026.3.22` (`e7d11f6c33e223a0dd8a21cfe01076bd76cef87a`),
`v2026.3.23` (`ccfeecb6887cd97937e33a71877ad512741e82b2`),
`v2026.3.28` (`f9b1079283a8ee25a7cee77c8f8225d5c813bc30`), and
`v2026.5.9-beta.1` (`0d3141ee2438c2c990241b8a0941efd69d35382c`).
No OpenClaw tag `v2026.5.9` was in the tag list retrieved on 2026-09-21.
The local version `2026.5.9` comes from commit
`4a93213212d5916c8fef76fc2043c3672a255f1b` (`chore: bump version to 2026.5.9
for scan command release`) and is not evidence of a sync to an upstream
revision.

## What remains unresolved

- The exact OpenClaw commit that was imported. Use tag `v2026.3.24` as the
  closest verified release, not as a proven parent.
- Whether any commit between `v2026.3.24` and `v2026.3.28` matches the import
  more closely. Those intermediate trees were not downloaded.
- The original copyright holder for `skills/skill-creator/license.txt`.
- The OpenProse commit that corresponds to the vendored skill pack.
- Whether npm publishes before 2026-03-27 belong to this codebase.
- Whether the canvas HTML still requires the Apache notice from upstream
  `vendor/a2ui/LICENSE`.
- Whether the 2026-09-21 OpenClaw Foundation copyright notice must also be
  preserved. It is recorded in `THIRD_PARTY_NOTICES.md` and was not swapped
  in over the `v2026.3.24` notice.
